# Shared Types (`packages/shared-types`)

The serialization contract between the web/BFF tier (`apps/web`) and the Python
Orbital Engine (`services/orbital-engine`). The TypeScript client here is **generated**
from the FastAPI OpenAPI schema so the two tiers cannot drift.

## Contents

| File | Source | Notes |
|---|---|---|
| `openapi.json` | exported from the engine | The OpenAPI document. Regenerate from Python. |
| `src/orbital-engine.ts` | generated by `openapi-typescript` | Path/response types. **Do not edit by hand.** |
| `src/index.ts` | hand-written | Re-exports the types + `createOrbitalEngineClient` (a typed `openapi-fetch` client). |

## Regenerating after an API change

The pipeline is two steps (Python → JSON → TypeScript):

```bash
# 1. Export the OpenAPI document from the engine (in the orbital-engine venv)
cd services/orbital-engine && . .venv/bin/activate && python -m orbital_engine.openapi

# 2. Regenerate the TypeScript client (from the repo root)
npm run gen:client
```

`npm run typecheck` (root) includes this package.

This is an npm workspace package consumed by `apps/web`.
